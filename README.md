# VFS Shell Emulator — Вариант 26

эмулятор UNIX-подобной консоли над виртуальной файловой
системой. VFS загружается из директории на диске в память и там
же изменяется

## Запуск

```
make run
python -m src.main --vfs ./sample_vfs
python -m src.main --vfs ./sample_vfs --script ./scripts/start.txt
```

## Параметры командной строки

| Флаг       | Назначение                               |
|------------|------------------------------------------|
| `--vfs`    | директория, дающая исходную VFS          |
| `--script` | стартовый скрипт                         |

## Команды

| Команда    | Описание                               |
|------------|----------------------------------------|
| `ls`       | список содержимого директории          |
| `cd`       | смена директории                       |
| `who`      | владельцы файлов и текущий пользователь|
| `wc`       | строки / слова / байты файла           |
| `chown`    | смена владельца (только в памяти)      |
| `vfs-info` | имя VFS и SHA-256 её содержимого       |
| `exit`     | выход                                  |

## Особенности

- Приглашение формируется из данных ОС: `user@host:~$`.
- Парсер раскрывает переменные окружения хоста (`$HOME` и т.п.).
- Стартовый скрипт печатает ввод, и вывод, а также останавливается на первой ошибке.
